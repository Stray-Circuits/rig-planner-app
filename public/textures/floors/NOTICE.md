# Floor textures

All five textures in this directory are sourced from [ambientCG](https://ambientcg.com/)
and released under the **CC0 1.0 Public Domain** license. No attribution is
required, but credit is given here as a matter of practice.

| File | Source asset | URL |
|---|---|---|
| `concrete_grey.jpg` | Concrete 020 | https://ambientcg.com/view?id=Concrete020 |
| `stage_black.jpg`   | Paint 005    | https://ambientcg.com/view?id=Paint005    |
| `carpet_beige.jpg`  | Carpet 016   | https://ambientcg.com/view?id=Carpet016   |
| `wood.jpg`          | Wood Floor 040 | https://ambientcg.com/view?id=WoodFloor040 |
| `sidewalk.jpg`      | Concrete 024 | https://ambientcg.com/view?id=Concrete024 |

Each file is the Color/Albedo map only, resized to 512×512 and re-encoded
at JPG quality 78 to keep the ship size around 280 KB total. The full PBR
sets (Normal, Roughness, Displacement, etc.) are available from the source
URLs above if a future feature needs them.
